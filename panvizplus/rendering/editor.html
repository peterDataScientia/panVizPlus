Molecular structure

LOCKED — ORIGINAL CHEMICAL STRUCTURE
Atoms, covalent bonds, bond order, coordinates, and molecular topology are immutable. The original molecule cannot be moved, resized, rotated, edited, added, deleted, or altered. A molecular bond may be clicked only to copy it as a new independent graphical bond.

Professional object controls

Selection: Click • Shift+Click multi-select • Ctrl+A select all annotations • Tab / Shift+Tab cycle.
Clipboard: Ctrl+C Copy • Ctrl+V Paste • Ctrl+X Cut • Ctrl+D Duplicate.
History: Ctrl+Z Undo • Ctrl+Y / Ctrl+Shift+Z Redo • Ctrl+S Save layout.
Object control: Arrow keys move 1 px • Shift+Arrow move 10 px • Alt+Arrow rotate 15° • Enter/F2 edit text • Delete removes selected objects • Esc clears selection.
Lines: Drag endpoints to resize dynamically • + / = expand • − compress • rotation/direction controls are available on the contextual ribbon.
Text: Ctrl+B / Ctrl+I / Ctrl+U apply formatting to the selected text object.

Legend editor

The legend is independently editable. Select the legend to open its object ribbon. Use the entry dropdown to add/remove/reorder interaction and bond entries, rename labels, change colors, line widths, dash styles, background, and text color. Removing a legend entry does not remove the underlying molecular interaction or bond.
